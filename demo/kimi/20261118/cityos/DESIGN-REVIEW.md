# CityOS 对标设计审查（Design Review）

> 2026-11-18 · 对照业内优秀智慧城市大屏 / 数字孪生系统的公开实践，审查梅塔维尔 CityOS 的差距并给出改进项。

## 一、调研来源

| 来源 | 关键实践 |
| --- | --- |
| 阿里云 DataV（数据可视化大屏） | 大屏按 **1920×1080 设计分辨率**制作，运行时按 `scale = min(vw/1920, vh/1080)` 整体缩放居中；16:9 构图、关键信息避开屏幕边缘 |
| 帆软 FineReport / 大屏设计指南 | KPI 控制在 **5~9 个**；大数字必须带**对比基准**（同比/环比/目标）；红/黄/绿状态色语义全站统一；图表选型矩阵：趋势=折线、占比=环图、对比=柱状 |
| Snap4City（ITU 收录的智慧城市数字孪生最佳实践） | 建筑/设施**拾取后展示元数据侧栏**；**图层与透明度控制**；事件预警流；**what-if 推演**；多角色视图 |
| 主流中后台（Ant Design Pro 等） | 明确的**下钻路径**：点击图表/区域逐级下钻、面包屑返回；骨架屏/懒加载；响应式与窄屏折叠侧栏 |
| 动效规范（Google Material / 业内心得） | 大屏动效"适度"：数据刷新用平滑过渡，**告警动画只在异常态出现**，避免全场闪烁造成视觉疲劳 |

## 二、规范矩阵 × CityOS 现状

| 规范项 | 业内做法 | CityOS 现状 | 差距 |
| --- | --- | --- | --- |
| 大屏分辨率适配 | 1920×1080 设计稿 + transform scale 自适应 | 流式布局，靠 flex 撑开，超宽/窄屏比例失调 | **待改** |
| KPI 数量与基准 | 5~9 个 + 同环比/目标对比 | 6 个 KPI，带同比/环比/目标 | ✅ 达标 |
| 状态色语义 | 红=告警、黄=关注、绿=正常，全站统一 | `--ok / --warn / --danger` 统一变量 | ✅ 达标 |
| 图表选型 | 趋势折线 / 占比环图 / 对比柱 | 各页已按此选型 | ✅ 达标 |
| 建筑拾取元数据 | Snap4City 式拾取侧栏 | 3D 沙盘拾取档案卡（用途/能耗/人口） | ✅ 达标 |
| 图层控制 | 图层开关 + 透明度 | 沙盘图层开关齐全 | ✅ 达标 |
| 事件预警 | 全局告警中心、跨页未读提醒 | 各页自管事件，**无全局告警中心** | **待改** |
| what-if 推演 | 参数可调的情景推演 | 预警规则引擎 + 应急调度模拟器 | ✅ 达标 |
| 下钻路径 | 图表点击 → 明细页，路径可回退 | 各页独立，**无跨页下钻联动** | **待改** |
| 动效克制 | 平滑过渡 + 告警态动画 | 事件闪烁已限告警态；**缺页面过渡、数字滚动** | 部分待改 |
| 响应式 | 窄屏折叠侧栏、骨架屏 | 流式可用但**侧栏不可折叠** | **待改** |

## 三、本轮改进清单（按优先级）

1. **大屏自适应**：screen.html 改为 1920×1080 设计稿 + `transform: scale()` 居中，任意窗口比例不变形（DataV 标准实践）。
2. **全局告警中心**：顶栏铃铛 + 未读角标，订阅 CityLive 事件流，下拉列最近 10 条，已读状态存 `localStorage`，跨页面生效。
3. **跨页下钻**：总览页城区对比图点击 → 跳转数据分析页并自动按该区筛选（URL 参数）；交通页道路列表点击 → 弹层显示该道路 24h 流量画像。
4. **侧栏折叠 + 页面过渡**：侧栏可收起（窄屏自动折叠），页面切换淡入，KPI 数字滚动动画。
5. **README 更新**：补充对标结论与新功能说明。

## 四、后续方向（ backlog ）

- 骨架屏加载态（首屏数据未到时的占位）
- 大屏轮播模式（无人值守自动切页）
- 多角色视图（指挥长 / 部门值班员不同首页）
- 移动端简化版
