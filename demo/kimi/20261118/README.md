# 武汉 CityOS · 城市运行管理中心（演示）

一套**纯静态**的智慧城市 / 数字孪生运营平台演示系统，以江城「武汉」为原型构建（长江穿城、三镇格局、黄鹤楼/龟山电视塔/江汉关/光谷星河地标），无需后端。数据由确定性模拟数据层生成，并由内置**实时仿真引擎**驱动持续变化（指标抖动、随机事件推送）。

## 快速开始

```bash
cd cityos
python3 -m http.server 8080   # 或 npx serve .
# 打开 http://localhost:8080
```

## 模块

| --- | --- | --- |

## 全局能力

- **全局告警中心**：顶栏铃铛 + 未读角标，订阅实时事件流，下拉收件箱（最近 30 条），已读状态经 `localStorage` 跨页持久化；严重事件铃铛震动提醒
- **侧栏折叠**：顶栏按钮收起为纯图标窄栏，偏好持久化，窄屏（<1100px）自动收起
- **跨页下钻**：总览城区图 → 数据分析页（URL 参数联动筛选）；交通拥堵榜 → 道路画像弹层
- **页面过渡**：切换淡入上移、KPI 数字滚动、告警态闪烁克制（仅异常时）

## 工程结构

```
cityos/
├── screen.html / index.html / sandbox.html(数智一张图) / traffic.html
├── energy.html / emergency.html / data.html / about.html
└── assets/
    ├── css/main.css     # 设计系统：令牌 + 布局 + 组件
    └── js/
        ├── data.js      # 模拟数据层（mulberry32 种子随机，刷新一致）
        ├── common.js    # 页面外壳、时钟、ECharts 主题、工具、全局告警中心、侧栏折叠
        └── live.js      # 实时仿真引擎：3s 指标抖动 + 8~16s 随机事件
```

依赖（均走 CDN）：Three.js r160、ECharts 5.5。

> 根目录的 `index.html`（本 README 同级）为早期独立的 3D 沙盘单页，与 `cityos/sandbox.html` 同源但不含后续交互增强。
