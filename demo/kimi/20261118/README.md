# 梅塔维尔 METAVILLE · 3D 城市地形沙盘

单文件 3D 地图展示页面（Three.js，CDN 引入，无需构建）。

## 运行

直接用浏览器打开 `index.html` 即可；或开启任意静态服务器：

```bash
npx serve .
# 或
python3 -m http.server 8080
```

> 由于使用了 ES Module + importmap（CDN 加载 three.js），需通过 http(s) 或支持模块加载的方式访问，建议用静态服务器打开。

## 场景内容

- **程序化地形**：Perlin 分形噪声生成山岭 / 丘陵 / 河谷，按海拔着色（河床→沙滩→草地→岩石→积雪）
- **蜿蜒河流 + 动态水面**：顶点波动动画，半透明高光水面
- **五大城区**：中央商务区（摩天楼群）、中城区、滨河住宅区、南部工业区、山岭公园
- **建筑实例化渲染**（InstancedMesh）：约千栋建筑，夜晚窗户自发光亮灯
- **跨河斜拉桥**：桥塔 + 12 根拉索
- **车流系统**：180 辆车沿路网双向行驶，过桥自动抬升
- **昼夜循环**：太阳方位 / 光照 / 天空颜色 / 星空 / 路灯实时联动（1 秒 ≈ 4 分钟）
- **氛围**：体积感雾效、漂移云朵、PCF 软阴影、ACES 色调映射
- **HUD**：实时帧率 / 建筑数 / 相机高度 / 时钟 / 指南针

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键拖拽 | 旋转视角 |
| 滚轮 | 缩放 |
| 右键拖拽 | 平移 |
| 切换夜晚 | 立即跳到 22:00 / 返回白天 |
| 自动环绕 | 相机绕城市旋转 |
| 车流开关 | 暂停 / 恢复车辆 |
| 重置视角 | 回到初始机位 |
